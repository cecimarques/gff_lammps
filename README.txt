# gff_lammps:

Here you can find a python code built for finding OPLS-AA force field potential parameters for any given compound in GROMACS .itp files and converting them into parameters for LAMMPS under real units. The code can be adapted for any force field, with OPLS-AA being merely an example, AND was designed to work in conjuncture with the 1-molecule topology LAMMPS data file that is generated by LigParGen (https://zarbi.chem.yale.edu/ligpargen/)*. Sample files specifically for phenol are given in the "Sample-input" directory.

* LigParGen does output the OPLS-AA potential parameters in the LAMMPS data file, but these were found (by me and also by others) to be bogus in many cases.
