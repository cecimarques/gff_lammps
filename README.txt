# gff_lammps:

Here you can find a python code built for finding OPLS-AA force field potential parameters for any given compound in GROMACS .itp files and converting them into parameters for LAMMPS under real units. The code can be adapted for any force field, with OPLS-AA being merely an example, AND was designed to work in conjuncture with the 1-molecule topology LAMMPS data file that is generated by LigParGen (https://zarbi.chem.yale.edu/ligpargen/)*. Sample files specifically for phenol are given in the "Sample-input" directory.

* LigParGen does output the OPLS-AA potential parameters in the LAMMPS data file, but these were found (by me and also by others) to be bogus in the case of many compounds.

INPUT FILES REQUIRED:
- ffnonbonded* : consists of a copy paste of the [ atomtypes ] section of the OPLS-AA ffnonbonded.itp file.
- ffbonds* : consists of a copy paste of the [ bondtypes ] section of the OPLS-AA ffbonded.itp file.
- ffangles* : consists of a copy paste of the [ angletypes ] section of the OPLS-AA ffbonded.itp file.
- ffdihedrals* : consists of a copy paste of the [ dihedraltypes ] section of the OPLS-AA ffbonded.itp file.
- bonds: file containing the content found in the "Bonds" section of the 1-molecule LAMMPS data file output by LigParGen. This input file is edited so that the columns are separated by "\t" separators.
- angles: file containing the content found in the "Angles" section of the 1-molecule LAMMPS data file output by LigParGen. This input file is edited so that the columns are separated by "\t" separators.
- dihedrals: file containing the content found in the "Dihedrals" section of the 1-molecule LAMMPS data file output by LigParGen. This input file is edited so that the columns are separated by "\t" separators.
- impropers: file containing the content found in the "Impropers" section of the 1-molecule LAMMPS data file output by LigParGen. This input file is edited so that the columns are separated by "\t" separators. 
* The four input files marked with "*" were built from the ffnonbonded.itp and bonded.itp file that can be found at https://github.com/gromacs/gromacs/tree/main for GROMACS version 2024.4 (date released 31/10/2024). Note that sometimes for bonded potential parameters information concerning specific directives are found split throughout the ffbonded.itp file.

Comments are presented to assist the reader along the code, but an overview can be found below:

 ------------------------------------------------------------------------- CODE OVERVIEW ---------------------------------------------------------------------------------------
 a) The first step is to assign the "OPLS-AA atom types" for the atoms in a molecule of the compound of interest. This should be doable under the assistance of the comment lines in the "atomtypes.atp" file. The "OPLS-AA atom types" for each atom are declared in the python code manually in ascending order with respect to atom IDs. Note that more than one atom can have the same "OPLS-AA atom type".
 b) The code is going to read the "ffnonbonded" file and search for the lines of the files that concern the "OPLS-AA atom types" you input and save their "atom name", "charge", "epsilon" and "sigma" values. The epsilon and sigma values are going to be output in the kernel in a format that can be directly copied/pasted into the LAMMPS data file. There will be one (and only one, since no repetition occurs!) line for each atom. The possibility of copying/pasting directly is unlocked by the fact that LigParGen outputs a 1-molecule LAMMPS data file that has a distinct LAMMPS "atom type" for each atom in the molecule. An array containing the charges is going to be saved into a file and can be easily plugged into 3rd column of the "Atoms" section (atom_style format full).
c) The code reads the "bonds", "ffbonds", "angles", "ffangles", "dihedrals", "ffdihedrals" files and uses them to find the potential parameter underlying each bond, angle and dihedral declared in the sections of the 1-molecule LAMMPS data file outut by LigParGen. This is done by associating the atom IDs for each atom with the GROMACS "atom name" and later finding the line in the "ffbonds", "ffangles" and "ffdihedrals" files that contain the parameters for the potential concerning the specific sequence of "atom names". This information is also output in the kernel in a format that allows direct copying/pasting in the LAMMPS data file. Such copying/pasting however needs to be done with caution because (1) the code outputs twice the parameters found in the lines of the GROMACS input files that contain bonds, angles and dihedrals that are formed by a palindrome sequence of atom names and (2) the code does not check for bonds, angles and dihedrals formed by a wildcard of atom names. Thus, the copying/pasting needs to be done mindfully (meaning deleting repeated lines and checking if indeed parameters for all bonds, angles and dihedrals were found. 

The .py code takes care of all necessary unit conversions required in the process of transforming GROMACS potential parameters to LAMMPS potential parameters for a LAMMPS input script that contemplates units "real". It also accounts for the differences in the potential form as implemented in GROMACS and LAMMPS (e.g., sometimes a pre-factor of 1/2 exists).

d) Finally, for impropers, the code simply outputs the list of "atom names" underlying each improper declared below the "Impropers" section in the 1-molecule LAMMPS data file gotten from LigParGen. It is responsibility of the user to see, based on the list of "atom names", if it is necessary to set an improper potential for any of the impropers in the list: there are very few occasions that this should occur as the list of improper potentials within the GROMACS .itp files is very short. It is worth mentioning on this matter that the official publication of the OPLS-AA prescribes no usage of improper potentials, with the ones advised by GROMACS probably therefore arising from extensions of the OPLS-AA force field that followed. Furthermore, it is worth mentioning that GROMACS advises implementing improper potentials as dihedral potentials and the corresponding potential form prescribed can be found in the original ffbonded.itp file in the GROMACS tree.
